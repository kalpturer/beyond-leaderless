# Beyond Leaderless

Evaluation code for **Beyond Leaderless: Randomized Consensus Against
Mobile Crashes**.

Requires Rust 1.87+, Python 3.10+, and [just](https://github.com/casey/just).

```sh
just setup   # install Python dependencies
just quick   # small experiment (~20 seconds)
just full    # all paper experiments and figures (~20 minutes)
```
